# 教學連結與原創琶音練習

「練習 → 教學連結」接受 YouTube 單支影片的長網址、分享短網址，以及 Shorts、Live 與嵌入網址。只保留標準影片網址供使用者回看。主題由使用者確認，題目、指法與示範音由遊戲產生。The Donut Doctor 的教學連結可用來試玩。

大三和小三和弦各從 C 的 1–3 弦開始。每題依序點出根音、三度、五度。相同和弦走完四個連續三弦組後，根音沿五度循環移動。試聽依實際指板位置逐音播放。

以 Godot 測試 12 個根音、4 個弦組、2 種主題，並驗證網址格式、答題順序與切頁計時。Chrome 桌面驗證貼入分享連結，手機尺寸驗證範例與原生網址輸入框，都經過選題及三音作答。
