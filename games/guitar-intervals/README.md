# 指板相對音程 · Fret Relations

獨立的 Godot 4.6 吉他指板學習原型。可從任意根音查音程、補和弦音，也可在指定弦組上練三和弦與完整七和弦的原位和轉位。

**[開啟網頁版原型](https://clydedesign2code.github.io/godot-games/guitar-intervals/)**。首頁顯示高音 123 弦上的 C 大三和弦。點音可試聽，選「查音程」可探索根音附近的位置。從查閱按「用這個練習」才進入作答。獨立練習入口也可進入雙音、和弦補音與讀譜。網頁讀譜可輸入音名或固定唱名，原生 macOS 版另支援麥克風口說。

## 從教學連結練琶音

進入「練習 → 教學連結」，貼上 YouTube 單支影片網址，或按「用範例連結」。自行確認要練大三或小三和弦琶音後按「開始練習」。第一題從 C 根音與 1–3 弦開始，依提示在指定弦上點出根音、三度、五度。按「試聽琶音」可逐音聽示範。答對後換弦組，每四組換根音。

題目與聲音由遊戲產生，連結保存在本次使用中，按「開啟原影片」可回到 YouTube。此流程不下載影片、字幕或音訊。

## 介面與視覺

面板採奶灰色外殼、深色指板與獨立按鍵，視覺參考 Teenage Engineering 的工業設計。[OP–1 field](https://teenage.engineering/products/op-1)、[EP–133 K.O. II](https://teenage.engineering/products/ep-133)

- 指板是主要顯示區；選音與發聲位置保留在同一個視覺範圍。
- 音程採左右配對的按鍵矩陣，方便比較小／大二度、三度、六度與七度；三和弦鍵顯示音級公式，掛留與七／六和弦鍵顯示和弦符號。和弦選項分成「基礎／掛留」與「七／六和弦」兩區，共用單一和弦選擇。
- 橘色表示根音與主要操作，藍色表示目標音，綠色表示和弦的五度／六度／七度；答對回饋使用獨立的綠色狀態。
- 首列直接切換「查和弦」「查音程」與「練習」。音量與靜音位於同列右側，窄螢幕則移到導覽下方。
- 網頁會依實際視窗寬度排列。琴枕左側的電吉他琴頭有六個弦鈕，查和弦時點任一個都能試聽該弦的空弦音。琴枕右側從第 1 品連續標到目前按法的最高品，至少顯示五品。寬度不足時依品號順序分行，各段均列出六條弦。
- 題目面板分成固定區域：題目、音程／和弦組成、練習統計、作答回饋與操作。和弦區先列完整公式與組成音，再列本題三音與省略音。根音、二／三／四度，以及五／六／七度各有選音格，顯示實際音名與弦品；未選位置的格子顯示「？」。選音進度獨立顯示，答對時保留原題目，成功訊息呈現在回饋區。提示、試聽與下一題分組排列。

## 開啟

使用 Godot 4.6 開啟本目錄的 `project.godot`，按 **F5** 執行。無需 addons、帳號或網路。預設視窗 1360 × 900，較小視窗可垂直捲動。

```sh
godot --path games/guitar-intervals
```

macOS 已安裝 Godot.app 時，可以在 monorepo 根目錄使用：

```sh
/Applications/Godot.app/Contents/MacOS/Godot --path games/guitar-intervals
```

### 發布測試版

在儲存庫根目錄執行下列指令。需要 Python 3、Git 推送權限、Godot 4.6.2 stable 及相同版本的單執行緒 Web release 匯出模板。Godot 已加入 PATH 時可省略 `GODOT_BIN`。

```sh
GODOT_BIN=/Applications/Godot.app/Contents/MacOS/Godot python3 games/guitar-intervals/tools/publish_web.py
```

腳本匯出遊戲，將八個執行與授權檔發到 `gh-pages`，再核對公開入口載入的版本、遊戲資料檔雜湊和 WebAssembly 回應。直接使用輸出的 `?v=…` 連結測試當次發布，日常可收藏本頁上方的固定入口。也可以先用 `tools/build_web.sh <輸出目錄>` 供本機瀏覽器試玩，再用 `publish_web.py --build-dir <已測試的目錄>` 發布同一份檔案。

## 五個模式

| 模式 | 操作 | 學習目的 |
| --- | --- | --- |
| 音程查閱 | 直接點選音程按鈕，單擊試聽、雙擊設定根音 | 建立根音周圍的位置記憶 |
| 雙音練習 | 根音固定，在指板點出指定音程的任一正確位置 | 將查閱轉成主動回想 |
| 三音和弦練習 | 根音固定，在另外兩條弦補上二度／三度／四度與五度／六度／七度；順序不限，完成前可再次點選取消 | 理解完整和弦與三音配置的關係 |
| 口說讀譜 | 隨機亮起一個不帶音名的圓點；按「開始口說」說出音名或固定唱名，也可輸入答案 | 看位置直接讀出音名 |
| 查和弦與弦組練習 | 選三、四或五條弦，再點小圖指定連續弦組。可直接試聽或遮住位置，亦可用同一組設定開始作答 | 比較同一和弦在不同弦組、轉位與把位的按法 |

根音欄顯示音名與弦品，例如 `F♯ · 6 弦 2 品`，不以空弦 E 代稱目前按出的音。**音程查閱**的 12 種音程按鍵可複選，所選項目會持續亮起，再點一次可各別取消，至少保留一項。查閱會同時標示所有所選音程的位置與符號；例如選大三度、五度、六度，C 根音會同時顯示 E、G、A 的位置。點亮起的指板位置可切換與根音一起播放的雙音，不將整個音程集合自動當成和弦播放。

**雙音練習**每次單選一個音程：根音加上一個目標音，共兩音；點其他音程會取代原選項。「下一題」及答對後自動切題會更換根音，持續練同一音程。**三音和弦練習**每次單選一種和弦：三和弦為根音加三度與五度，掛留和弦以二度或四度取代三度；七／六和弦固定省略純五度，改為根音加三度與七度／六度，共三音。按鍵區分別標示「複選」或「單選」，並說明練習的音數；較窄視窗的按鍵會自動換行。

查閱音程集合、雙音的單一音程、和弦種類各自保存。「用這個練習」沿用查閱的根音和目前試聽的單一音程。返回查閱可繼續探索原本的複選集合。

查閱、雙音與三音和弦模式可直接**雙擊任一指板位置設定根音**，包括亮起範圍外的位置；選定後試聽，圓圈與根音欄顯示音名。單擊仍用來試聽或作答，雙擊設定根音不計為作答或錯答，會重新開始當題並取消舊題的換題計時。

也可按「在指板選根音」後單擊位置；此時暫時顯示整張指板的音名，選定後回到原本的試聽或作答模式。按「取消選根音」可保留原根音、已選音與回饋；選根音期間暫停自動換題，取消後若原題已答對，會重新顯示完整的回饋停留時間。口說讀譜是隨機位置測驗，不設定根音。

範圍預設為根音左右各 4 品；關閉限制可使用整個 0–15 品指板。查閱可開啟整張指板音名；練習隱藏未選位置的音名與答案，點選後仍會顯示該音名。變更根音、查閱集合、練習音程、和弦種類或範圍會重新開始當題並取消舊計時。查閱只剩一項時重按該項，或練習時重按目前單選項目，會保留目前進度與試聽狀態。

答對完整題目後，題目區會顯示綠色「答對了！」回饋，停留約 1.6 秒後自動進入下一題；三音和弦需補齊兩個音才會切題。也可按「立即下一題」跳過等待。「下一題」隨機更換根音，保留所選音程或和弦種類。錯答可重試，提示會提供一個答案的位移；查看答案不計為完成，也不會自動切題。獨立完成、提示後完成與錯點次數分別計算，僅保留於本次執行。等待期間更換模式、題目設定或手動切題，會取消原題的自動切題計時。

## 弦組轉位

在「查和弦」直接點根音、和弦種類或轉位。三弦有 123、234、345、456 四組，四弦有 1234、2345、3456 三組，五弦有 **12345** 與 **23456** 兩組。每組小圖上方是第 1 弦，下方是第 6 弦。查閱指板從琴枕起顯示到目前把位，左側保留可點的空弦，試聽使用每條弦實際的音高。

「弦數」決定要用幾條弦，「弦組」小圖決定要用哪幾條。選第一轉位（窄螢幕顯示「一轉」），指板標題會顯示完整和弦符號，例如 Cm7/E♭。

maj7、7、m7、mMaj7 在三條弦上使用根音、三度與七度，6、m6 則保留六度。四條弦可彈出完整四音，五條弦再重複一個和弦音。半減七和弦與減七和弦使用四或五條弦，都保留變化五度。三和弦與掛留和弦在五條弦上保留全部三個組成音，其餘兩條弦也取自這三個音。轉位按實際最低音判定。五弦指法可用空弦與橫按，以最多四根左手手指完成。[Open Music Theory 的轉位說明](https://viva.pressbooks.pub/openmusictheory/chapter/seventh-chords/)

想聽出差別，可選 **C → m7 → 原位**，在 **234 弦**試聽 C、E♭、B♭。切到 **4 條弦**的 **2345** 會補回五度 G。再切到 **5 條弦**的 **23456**，第一個指法在高八度再加一個 G，從低到高為 **C–G–B♭–E♭–G**。每次切換後按「試聽和弦」，可對照指板上的實際位置。

選 C 大三和弦，保持同一個轉位，切換弦組就能比較兩種按法。下表的品數一律按粗弦到細弦排列，0 表示空弦。高音組跨過 G 弦和 B 弦，兩弦的空弦只差四個半音。

| C 大三和弦 | 123 弦組（第 3、2、1 弦品數） | 456 弦組（第 6、5、4 弦品數） | 由低到高 |
| --- | --- | --- | --- |
| 原位 C | 5、5、3 | 8、7、5 | C、E、G |
| 第一轉位 C/E | 9、8、8 | 12、10、10 | E、G、C |
| 第二轉位 C/G | 0、1、0 | 3、3、2 | G、C、E |

七和弦也能直接比較。例如 C7/B♭ 在第 4、3、2、1 弦可按 **8、9、8、8**，在第 6、5、4、3 弦可按 **6、7、5、5**。兩組都是 B♭、E、G、C，高音組整體高一個八度。大三、小三、m7、maj7、7 可直接點選。「更多和弦」含 sus2、sus4、6、m6、減、增、mMaj7、半減七與減七。各種類都可移到 12 個根音。

查閱會列出每條弦的音名、品位與建議使用的手指名稱。開啟「顯示指法」可在按弦圓點旁看到手指名稱，預設關閉。空弦不標手指。有多種指法時可逐一比較。按播放鍵可聽目前的位置，「遮住位置」可讓你自行回想。

圓點可切換 **音名**、**音程** 或 **兩者**。例如 Gm7 的 G、B♭、D、F 對應 R、m3、5、m7；選「兩者」會在同一個圓點分兩行顯示。Gm7/B♭ 的最低音 B♭ 仍標成 m3，因為和弦根音仍是 G。音名省略八度數字，試聽則依每一弦的實際品位發聲。

按 **用這個練習** 會將目前和弦、弦組與轉位帶入作答。作答順序不限，再點已選位置可取消。完整答對後約 1.6 秒換根音。「返回查閱」恢復開始練習前的和弦及把位。

示範優先使用密集排列的三和弦與 drop-2 七和弦。題目也接受其他符合條件的排列。使用 0–15 品，按下的最高與最低品最多相差 4 品，空弦不計入跨度。指號 1、2、3、4 依序為食指、中指、無名指、小指，實際用指可依手型調整。

## 口說讀譜：音名與固定唱名

從「練習」進入「指板讀譜」。接受 A–G 與固定唱名 C＝Do、D＝Re、E＝Mi、F＝Fa、G＝Sol／So、A＝La、B＝Si／Ti。升降音可用 `F sharp`、`B flat`、`升 Fa`、`降 Si`，等音視為相同音級，例如 F♯／G♭。開始可只練自然音，關閉「先練自然音 A–G」後涵蓋全部 0–15 品。

口說流程：

1. 按橘色「開始口說」後顯示「正在準備麥克風」，此時先不用說話；首次使用請允許系統權限。按鈕暫時停用，仍可取消。
2. 真正啟動輸入裝置後，顯示綠色「請開始說話」，此時說一個音名或唱名。音量條反映收音，旁邊顯示剩餘秒數，按鈕變成紅色「說完了 · 停止收音」。
3. 說完按停止按鈕，不需等待靜音自動送出。最多收音 **10 秒**，倒數結束也會停止。停止確認前顯示「請停止說話」；收到原生元件確認後明示「收音已停止，正在辨識」，不用再說話。
4. 顯示辨識文字並判題。沒有清楚聲音、低信心、不含單一音名、候選衝突、權限或模型錯誤都不計錯；提供「重新錄音」及輸入答案。

只有最終且信心足夠、替代候選沒有音名衝突的結果會判題。錄音期間不因中途停頓自動送出；原生元件先在記憶體內保存最多 10 秒 PCM，停止收音後才交給裝置端辨識，沒有錄音檔。準備／收音／辨識期間停用語言、題型、輸入答案與試聽提示，避免同時播放或修改輸入；取消、切題、換模式與揭答仍會終止原請求。舊請求結果及過期音量更新不能影響新題或重新開啟停止按鈕。

開始與重試按鈕的預設、hover、按下使用同一橘色系列；收音中的停止操作使用紅色系列，文字保持對比。準備、停止確認與辨識中才停用按鈕，並以文字說明正在做什麼。

答對顯示音名，1.6 秒後自動切題；錯答可重試。點選指板也會試聽並在該圓圈內顯示音名，這與「聽音提示」都會將當題標成提示完成；「查看音名」不計完成，也不自動切題。英文辨識可說字母或 Do–Si；以中文說「升／降」可選「中文」辨識。辨識文字若被誤聽，可以重說，或改用同一套判題規則的輸入欄。

macOS 原型使用系統 [Speech／SFSpeechRecognizer](https://developer.apple.com/documentation/speech/sfspeechrecognizer)，強制使用裝置端模型；缺少模型時顯示說明，不改送雲端、不儲存錄音。首次按下需允許 **FR–12 Voice** 的語音辨識與麥克風權限。開發機需安裝 Xcode Command Line Tools，先建立獨立的原生輔助 App：

```sh
bash games/guitar-intervals/tools/build_voice_macos.sh
```

語音元件位於本機 `build/NoteSpeech.app`，可重建、不納入 Git 或 Godot 資源匯入。一般 Godot 專案仍可在沒有此元件時啟動並使用輸入答案。目前此元件只接 macOS 開發版；iPad／iOS 需另外實作原生橋接與 App 權限／簽署，不能直接使用 macOS helper。Apple 裝置端語言模型與實際辨識效果依設備、系統及發音而異。

## 聲音與位置一起練習

- **單音**：點指板試聽該位置的實際音高，包括錯答的位置；音名直接顯示在點選圓圈內，例如 `E`、`F♯`，指板下方同時顯示完整弦／品位置。音名在聲音結束或靜音時仍保留，下一次點選／合奏時更新，切題時清除。完成或揭答後仍可點音比較，不會重複判題。
- **設定根音**：平時點音試聽或作答，根音保持固定。按「在指板選根音」，再直接點選新位置；設定後自動回到原本模式。
- **雙音**：查閱中點亮起的目標音，目標音外圈會標出選定位置，再按「播放雙音」與根音一起聽。尚未選擇時預選一個靠近根音、優先符合指定向上距離的可用位置。雙音練習完成或揭答後也可播放；揭答時可點另一個正確位置比較不同排列。
- **三音和弦**：先選一個和弦音時可播放雙音；補齊兩個音後，按「播放三音」同時聽到三音，包括七／六和弦的省略配置。揭答後可直接播放顯示的指型。
- **視覺回饋**：白色外圈標示正在發聲的位置；結束、靜音或切題後清除。音名會保留供對照，下一次點選／合奏時更新、切題時清除；靜音或關閉整張指板音名時，仍會顯示這次所選音名。雙音／三音和弦會列出所有合奏音名。右上角提供音量與靜音；音量為零時不會啟動聲音。重播不改變成績。

使用離線合成的撥弦參考音色，十二平均律、A4 = 440 Hz。每一組聲音先混成同一條 44.1 kHz／16-bit PCM，讓最多五條弦的各聲部在同一取樣點開始。起音與尾音有包絡，依聲部數保留混音餘裕。快速點選會取代前一次播放。[Godot AudioStreamWAV](https://docs.godotengine.org/en/4.6/classes/class_audiostreamwav.html)、[Godot AudioStreamPlayer](https://docs.godotengine.org/en/4.6/classes/class_audiostreamplayer.html)

播放依據**實際弦與品位的 MIDI 音高**。例如選 C3 與低於它的 E2，便會播放 C3 + E2，同音級的 E3 或 E4 會有不同的實際聽感。在弦組轉位可先聽題目和弦，答案位置仍隱藏。開始選音後，播放鍵會試聽已選的弦品。

## 音樂與判題規則

- 六弦標準調弦，從粗到細為 **E2–A2–D3–G3–B3–E4**。畫面頂端是細弦 1 弦，底端是粗弦 6 弦。
- 音高依實際調弦加上品位計算。G、B 弦相差 4 半音，其餘相鄰弦相差 5 半音，不使用固定跨弦形狀硬編碼。
- 查閱與雙音訓練採用**八度等價的相對音級關係**，公式為 `(目標 MIDI − 根音 MIDI) mod 12`。例如 C3 的「大三度音級」接受 E2、E3、E4 的位置。C3–E2 的實際有向距離是 −8 半音。弦組轉位另檢查最低發聲音高。
- 同音級／八度練習排除已給定的根音位置，接受其他同音級位置；不另考「指定向上／向下／限定八度」的音程距離。
- 三和弦包含大三和弦 `1–3–5`、小三和弦 `1–♭3–5`、減三和弦 `1–♭3–♭5`、增三和弦 `1–3–♯5`。參考：[Open Music Theory — Triads](https://viva.pressbooks.pub/openmusictheory/chapter/triads/)。
- 掛留和弦有 `sus2`（`1–2–5`）與 `sus4`（`1–4–5`），保留根音與五度，以二度／四度取代三度。例如 Csus2 為 C–D–G，Csus4 為 C–F–G；大／小三度都不能作答。題目列完整組成與本題三音，選音格、提示及播放依實際二／四度運作。參考：[Open Music Theory — Chord Symbols](https://viva.pressbooks.pub/openmusictheory/chapter/chord-symbols/)。
- 七／六和弦新增 `maj7`、`7`、`m7`、`mMaj7`、`6`、`m6`。完整四音公式與本題三音配置分開保存；保留根音、三度與七度／六度，固定省略純五度。小六和弦的六度仍是大六度。參考：[UNCW — Shell Voicings](https://people.uncw.edu/russellr/ShellVoicings.html)、[Tom Lippincott — Shell Voicings](https://tomlippincott.com/shell-voicings)。
- 題目會在作答前列出完整組成音與本題三音，例如 C7 完整為 C–E–G–B♭，本題為 C–E–B♭，明示省略 G。音名是學習輔助，玩家需找弦品位置；固定根音後只補兩音。省略的五度不能替代必要的七／六度。減／增三和弦仍保留變化五度；本版未加入半減七／減七的三音省略題。
- 三個音必須位於不同弦，非空弦的最高／最低品差最多 4 品，並包含給定的根音。這是初步的可彈奏篩選，尚未評估個別手指配置、弦間跨度與手掌大小。
- 每次三音和弦選音都必須能延伸成符合上述規則的完整答案，避免選到正確音級卻無法補完。無答案的手動設定會顯示說明；隨機出題只使用有解的根音。
- 指板音名採常用等音名；題目／和弦答案則按音級拼寫，例如 C 增三和弦的第五音為 G♯，不是 A♭。六半音查閱統一按減五度拼寫，符號為 ♭5。

口說模式另執行 `godot --path games/guitar-intervals --script res://tests/test_voice.gd -- --capture-dir=/tmp/fret-voice`。測試會啟動已編譯的原生 App 走測試結果協定，並驗證雙命名、低信心／衝突候選、錯答、等音、提示／揭答、逾期結果隔離與自動切題；不會請求權限或錄音。這些測試不代表真人麥克風辨識準確度，仍需使用者授權後以實際發音驗證。

## 原型邊界與後續方向

目前是桌面視聽學習原型，具 macOS 口說辨識橋接與多音程查閱。尚未提供混合音程出題、真人語音準確度驗證、吉他彈奏音高作答、真實吉他取樣、替代調弦、左手指板、七弦琴、進度存檔、iOS 語音元件、手機版或匯出安裝檔。

後續可驗證使用者能否將音程與固定弦組的指法移到不同根音，再依結果加入弱項重複練習與聽辨題。
