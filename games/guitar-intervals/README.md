# 指板相對音程 · Fret Relations

獨立的 Godot 4.6 吉他指板學習原型。目標是讓使用者從任意根音出發，把音程記成可以移動的跨弦／跨品位置，再用同樣的關係組成三和弦。

## 開啟

使用 Godot 4.6 開啟本目錄的 `project.godot`，按 **F5** 執行。無需 addons、帳號或網路。預設視窗 1360 × 900，較小視窗可垂直捲動。

```sh
godot --path games/guitar-intervals
```

macOS 已安裝 Godot.app 時，可以在 monorepo 根目錄使用：

```sh
/Applications/Godot.app/Contents/MacOS/Godot --path games/guitar-intervals
```

## 三個模式

| 模式 | 操作 | 學習目的 |
| --- | --- | --- |
| 音程查閱 | 點音試聽，切換「點選：設根音」後指定根音；懸停查看弦／品位移與實際半音差 | 建立根音周圍的位置記憶 |
| 雙音練習 | 根音固定，在指板點出指定音程的任一正確位置 | 將查閱轉成主動回想 |
| 三和弦練習 | 根音固定，在另外兩條弦各補一個音；三度或五度可先選，完成前可再次點選取消 | 理解和弦的音程組成 |

範圍預設為根音左右各 4 品；關閉限制可使用整個 0–15 品指板。查閱可開啟音名，練習時會隱藏音名及答案提示。根音也可用弦／品控制項指定；更換根音、音程、和弦種類或範圍會重新開始當題。

「下一題」隨機更換根音，保留所選音程或和弦種類，方便針對同一種形狀練習。錯答可重試，提示會提供一個答案的位移；查看答案不計為完成。獨立完成、提示後完成與錯點次數分別計算，僅保留於本次執行。

## 聲音與位置一起練習

- **單音**：三個模式都可點指板試聽該位置的實際音高，包括錯答的位置；完成或揭答後仍可點音比較，不會重複判題。
- **設定根音**：查閱預設為試聽，根音保持固定。點「點選：試聽」切換成「點選：設根音」，再點新根音，設定後自動回到試聽；也可用上方弦／品控制項調整。
- **雙音**：查閱中點亮起的目標音，金色外圈會標出選定位置，再按「播放雙音」與根音一起聽。尚未選擇時預選一個靠近根音、優先符合指定向上距離的可用位置。雙音練習完成或揭答後也可播放；揭答時可點另一個正確位置比較不同排列。
- **三和弦**：先選一個和弦音時可播放雙音；補齊兩個音後，按「播放三和弦」同時聽到三音。揭答後可直接播放顯示的指型。
- **視覺回饋**：白色外圈標示正在發聲的位置；結束、靜音或切題後清除。右上角提供音量與靜音；音量為零時不會啟動聲音。重播不改變成績。

使用離線合成的撥弦參考音色，十二平均律、A4 = 440 Hz，並非錄製的真實吉他取樣。每一組聲音先混成同一條 44.1 kHz／16-bit PCM，再交給 Godot 的 [AudioStreamWAV](https://docs.godotengine.org/en/4.6/classes/class_audiostreamwav.html)／[AudioStreamPlayer](https://docs.godotengine.org/en/4.6/classes/class_audiostreamplayer.html)，讓雙音／三和弦各聲部在同一取樣點開始。起音與尾音有包絡、依聲部數保留混音餘裕；快速點選會取代前一次播放。

播放依據**實際弦與品位的 MIDI 音高**，不把音折回同一個八度。例如選 C3 與低於它的 E2，便會播放 C3 + E2；同音級的 E3 或 E4 會有不同的實際聽感。試聽不會預先洩漏未選定的練習答案，練習中的合奏按鈕會等選音或揭答後才啟用。

## 音樂與判題規則

- 六弦標準調弦，從粗到細為 **E2–A2–D3–G3–B3–E4**。畫面頂端是細弦 1 弦，底端是粗弦 6 弦。
- 音高依實際調弦加上品位計算。G、B 弦相差 4 半音，其餘相鄰弦相差 5 半音，不使用固定跨弦形狀硬編碼。
- 本版訓練的是**相對音級關係，包含八度等價**：`(目標 MIDI − 根音 MIDI) mod 12`。例如 C3 的「大三度音級」接受 E2、E3、E4 的位置。C3–E2 的實際有向距離是 −8 半音，畫面不把它當作實際向上的大三度。這項規則會在指板下方持續顯示。
- 同音級／八度練習排除已給定的根音位置，接受其他同音級位置；不另考「指定向上／向下／限定八度」的音程距離。
- 三和弦包含大三和弦 `1–3–5`、小三和弦 `1–♭3–5`、減三和弦 `1–♭3–♭5`、增三和弦 `1–3–♯5`。參考：[Open Music Theory — Triads](https://viva.pressbooks.pub/openmusictheory/chapter/triads/)。
- 三個音必須位於不同弦，非空弦的最高／最低品差最多 4 品，並包含給定的根音。這是初步的可彈奏篩選，尚未評估個別手指配置、弦間跨度與手掌大小。
- 每次三和弦選音都必須能延伸成符合上述規則的完整答案，避免選到正確音級卻無法補完。無答案的手動設定會顯示說明；隨機出題只使用有解的根音。
- 指板音名採常用等音名；題目／和弦答案則按音級拼寫，例如 C 增三和弦的第五音為 G♯，不是 A♭。六半音查閱統一按減五度拼寫，符號為 ♭5。

## 實作結構

```text
src/theory/fretboard_theory.gd  # 純音高、音程、拼寫、範圍及三和弦指型計算
src/fretboard/fretboard.gd      # 指板繪製、懸停、位置命中與點選訊號
src/trainer/trainer.gd         # 三種模式、作答狀態、回饋與當次統計
src/trainer/trainer.tscn       # 主場景
src/audio/tone_player.gd       # 參考音合成、同步合奏、快取、音量與播放生命週期
tests/test_runner.gd          # 音樂模型與真實 viewport 點擊測試
assets/fonts/                 # Noto Sans TC 及 SIL Open Font License
```

中文字型使用隨專案附帶的 [Google Fonts Noto Sans TC](https://github.com/google/fonts/tree/main/ofl/notosanstc)，授權見 `assets/fonts/OFL.txt`；無需依賴作業系統已安裝的中文字型。所有資源使用 `res://` 路徑，不依賴其他遊戲專案。

## 驗證

```sh
godot --headless --path games/guitar-intervals --editor --import --quit
godot --headless --path games/guitar-intervals --script res://tests/test_runner.gd
```

實際圖形渲染與截圖驗證：

```sh
godot --path games/guitar-intervals --script res://tests/test_runner.gd -- --capture-dir=/tmp/fret-relations
```

測試包含全部 96 個根音位置、12 種音級關係、兩種範圍、四種三和弦，以及滑鼠點選查閱、錯答重試、提示、揭答、取消選音、先選五度、統計與題目切換。聲音測試以頻譜偵測確認單音與和弦各聲部的實際 PCM 頻率，並透過 AudioEffectCapture 檢查引擎音訊匯流排確實輸出非零樣本；另驗證靜音、音量、跨八度、重播計分與白圈生命週期。圖形模式額外輸出畫面及單音／雙音／三和弦 WAV 預覽。

## 原型邊界與後續方向

目前是桌面視聽學習原型，尚未提供真實吉他取樣、麥克風辨識、替代調弦、左手指板、七弦琴、進度存檔、混合音程出題、手機版或匯出安裝檔。

後續可優先驗證：使用者能否把三度與六度的位置記憶遷移到不同根音；再依結果加入弱項重複練習、限定弦組、三和弦轉位與聽辨題。指定音高方向／八度的進階題型應使用實際 MIDI 差距判題，與目前的音級練習明確區分。
