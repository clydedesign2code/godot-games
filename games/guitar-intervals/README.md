# 指板相對音程 · Fret Relations

獨立的 Godot 4.6 吉他指板學習原型。目標是讓使用者從任意根音出發，把音程記成可以移動的跨弦／跨品位置，再用同樣的關係組成三和弦。

## 介面與視覺

FR–12 的面板以 [Teenage Engineering OP–1 field](https://teenage.engineering/products/op-1) 與 [EP–133 K.O. II](https://teenage.engineering/products/ep-133) 的工業設計為參考：奶灰色霧面外殼、深色顯示區、印刷式標示、等寬數字與有按壓層次的獨立按鍵。介面使用專案自身的圖形與型號，不依賴產品照片作為畫面素材。

- 指板是主要顯示區；選音與發聲位置保留在同一個視覺範圍。
- 音程採左右配對的按鍵矩陣，方便比較小／大二度、三度、六度與七度；和弦鍵直接顯示音級公式。
- 橘色表示根音與主要操作，藍色表示目標音，綠色表示五度；答對回饋使用獨立的綠色狀態。
- 右上角保留可操作的音量與靜音，數字會跟隨音量滑桿更新。
- 較窄視窗會把指板與按鍵區上下排列；目前驗證為桌面視窗佈局，尚未在 iPad 實機驗證。

## 開啟

使用 Godot 4.6 開啟本目錄的 `project.godot`，按 **F5** 執行。無需 addons、帳號或網路。預設視窗 1360 × 900，較小視窗可垂直捲動。

```sh
godot --path games/guitar-intervals
```

macOS 已安裝 Godot.app 時，可以在 monorepo 根目錄使用：

```sh
/Applications/Godot.app/Contents/MacOS/Godot --path games/guitar-intervals
```

## 四個模式

| 模式 | 操作 | 學習目的 |
| --- | --- | --- |
| 音程查閱 | 直接點選音程按鈕，單擊試聽、雙擊設定根音 | 建立根音周圍的位置記憶 |
| 雙音練習 | 根音固定，在指板點出指定音程的任一正確位置 | 將查閱轉成主動回想 |
| 三和弦練習 | 根音固定，在另外兩條弦各補一個音；三度或五度可先選，完成前可再次點選取消 | 理解和弦的音程組成 |
| 口說讀譜 | 隨機亮起一個不帶音名的圓點；按「開始口說」說出音名或固定唱名，也可輸入答案 | 看位置直接讀出音名 |

根音欄直接顯示實際音名、八度與位置，例如 `F♯2 · 6 弦 2 品`，不以空弦 E 代稱目前按出的音。12 種音程與四種三和弦採平鋪按鈕，當前選項會亮起，可直接比較大小三度、大小六度或和弦公式；較窄視窗會自動換行。

查閱、雙音與三和弦模式可直接**雙擊任一指板位置設定根音**，包括亮起範圍外的位置；選定後試聽，圓圈與根音欄顯示音名。單擊仍用來試聽或作答，雙擊設定根音不計為作答或錯答，會重新開始當題並取消舊題的換題計時。

也可按「在指板選根音」後單擊位置；此時暫時顯示整張指板的音名，選定後回到原本的試聽或作答模式。按「取消選根音」可保留原根音、已選音與回饋；選根音期間暫停自動換題，取消後若原題已答對，會重新顯示完整的回饋停留時間。口說讀譜是隨機位置測驗，不設定根音。

範圍預設為根音左右各 4 品；關閉限制可使用整個 0–15 品指板。查閱可開啟整張指板音名；練習隱藏未選位置的音名與答案，點選後仍會顯示該音名。選定新根音、音程、和弦種類或範圍會重新開始當題；再次點選已亮起的音程／和弦按鈕會保留目前狀態。

答對完整題目後，題目區會顯示綠色「答對了！」回饋，停留約 1.6 秒後自動進入下一題；三和弦需補齊兩個音才會切題。也可按「立即下一題」跳過等待。「下一題」隨機更換根音，保留所選音程或和弦種類，方便針對同一種形狀練習。錯答可重試，提示會提供一個答案的位移；查看答案不計為完成，也不會自動切題。獨立完成、提示後完成與錯點次數分別計算，僅保留於本次執行。等待期間更換模式、題目設定或手動切題，會取消原題的自動切題計時。

## 口說讀譜：音名與固定唱名

第四個模式同時接受 A–G 與固定唱名 C＝Do、D＝Re、E＝Mi、F＝Fa、G＝Sol／So、A＝La、B＝Si／Ti，不必切換答案種類。升降音可說 `F sharp`、`B flat`、`升 Fa`、`降 Si`；等音視為相同音級，例如 F♯／G♭。只考名稱，不考歌唱音準或八度。開始可只練自然音，關閉「先練自然音 A–G」後涵蓋全部 0–15 品。

按下「開始口說」才啟動短時聆聽；稍停約 1.6 秒或按「完成說話」結束輸入，最長聆聽約 8 秒。畫面顯示辨識文字；只對最終且信心足夠、替代候選沒有音名衝突的結果判題。低信心、不含單一音名、未授權、模型或輸入裝置不可用都不計錯。取消、切題、切換模式／辨識語言、查看答案與輸入作答會停止原本的語音請求，舊請求結果不能套用到新題。

答對顯示音名，1.6 秒後自動切題；錯答可重試。點選指板也會試聽並在該圓圈內顯示實際音名與八度，這與「聽音提示」都會將當題標成提示完成；「查看音名」不計完成，也不自動切題。英文辨識可說字母或 Do–Si；以中文說「升／降」可選「中文」辨識。辨識文字若被誤聽，可以重說，或改用同一套判題規則的輸入欄。

macOS 原型使用系統 [Speech／SFSpeechRecognizer](https://developer.apple.com/documentation/speech/sfspeechrecognizer)，強制使用裝置端模型；缺少模型時顯示說明，不改送雲端、不儲存錄音。首次按下需允許 **FR–12 Voice** 的語音辨識與麥克風權限。開發機需安裝 Xcode Command Line Tools，先建立獨立的原生輔助 App：

```sh
bash games/guitar-intervals/tools/build_voice_macos.sh
```

語音元件位於本機 `build/NoteSpeech.app`，可重建、不納入 Git 或 Godot 資源匯入。一般 Godot 專案仍可在沒有此元件時啟動並使用輸入答案。目前此元件只接 macOS 開發版；iPad／iOS 需另外實作原生橋接與 App 權限／簽署，不能直接使用 macOS helper。Apple 裝置端語言模型與實際辨識效果依設備、系統及發音而異。

## 聲音與位置一起練習

- **單音**：點指板試聽該位置的實際音高，包括錯答的位置；音名與八度直接顯示在點選圓圈內，例如 `E3`、`F♯3`，指板下方同時顯示完整弦／品位置。音名在聲音結束或靜音時仍保留，下一次點選／合奏時更新，切題時清除。完成或揭答後仍可點音比較，不會重複判題。
- **設定根音**：平時點音試聽或作答，根音保持固定。按「在指板選根音」，再直接點選新位置；設定後自動回到原本模式。
- **雙音**：查閱中點亮起的目標音，目標音外圈會標出選定位置，再按「播放雙音」與根音一起聽。尚未選擇時預選一個靠近根音、優先符合指定向上距離的可用位置。雙音練習完成或揭答後也可播放；揭答時可點另一個正確位置比較不同排列。
- **三和弦**：先選一個和弦音時可播放雙音；補齊兩個音後，按「播放三和弦」同時聽到三音。揭答後可直接播放顯示的指型。
- **視覺回饋**：白色外圈標示正在發聲的位置；結束、靜音或切題後清除。音名會保留供對照，下一次點選／合奏時更新、切題時清除；靜音或關閉整張指板音名時，仍會顯示這次所選音名。雙音／三和弦會列出所有合奏音名。右上角提供音量與靜音；音量為零時不會啟動聲音。重播不改變成績。

使用離線合成的撥弦參考音色，十二平均律、A4 = 440 Hz，並非錄製的真實吉他取樣。每一組聲音先混成同一條 44.1 kHz／16-bit PCM，再交給 Godot 的 [AudioStreamWAV](https://docs.godotengine.org/en/4.6/classes/class_audiostreamwav.html)／[AudioStreamPlayer](https://docs.godotengine.org/en/4.6/classes/class_audiostreamplayer.html)，讓雙音／三和弦各聲部在同一取樣點開始。起音與尾音有包絡、依聲部數保留混音餘裕；快速點選會取代前一次播放。

播放依據**實際弦與品位的 MIDI 音高**，不把音折回同一個八度。例如選 C3 與低於它的 E2，便會播放 C3 + E2；同音級的 E3 或 E4 會有不同的實際聽感。試聽不會預先洩漏未選定的練習答案，練習中的合奏按鈕會等選音或揭答後才啟用。

## 音樂與判題規則

- 六弦標準調弦，從粗到細為 **E2–A2–D3–G3–B3–E4**。畫面頂端是細弦 1 弦，底端是粗弦 6 弦。
- 音高依實際調弦加上品位計算。G、B 弦相差 4 半音，其餘相鄰弦相差 5 半音，不使用固定跨弦形狀硬編碼。
- 本版訓練的是**相對音級關係，包含八度等價**：`(目標 MIDI − 根音 MIDI) mod 12`。例如 C3 的「大三度音級」接受 E2、E3、E4 的位置。C3–E2 的實際有向距離是 −8 半音，畫面不把它當作實際向上的大三度。這項規則會在指板下方持續顯示。
- 同音級／八度練習排除已給定的根音位置，接受其他同音級位置；不另考「指定向上／向下／限定八度」的音程距離。
- 三和弦包含大三和弦 `1–3–5`、小三和弦 `1–♭3–5`、減三和弦 `1–♭3–♭5`、增三和弦 `1–3–♯5`。參考：[Open Music Theory — Triads](https://viva.pressbooks.pub/openmusictheory/chapter/triads/)。
- 三個音必須位於不同弦，非空弦的最高／最低品差最多 4 品，並包含給定的根音。這是初步的可彈奏篩選，尚未評估個別手指配置、弦間跨度與手掌大小。
- 每次三和弦選音都必須能延伸成符合上述規則的完整答案，避免選到正確音級卻無法補完。無答案的手動設定會顯示說明；隨機出題只使用有解的根音。
- 指板音名採常用等音名；題目／和弦答案則按音級拼寫，例如 C 增三和弦的第五音為 G♯，不是 A♭。六半音查閱統一按減五度拼寫，符號為 ♭5。

## 實作結構

```text
src/theory/fretboard_theory.gd  # 純音高、音程、拼寫、範圍及三和弦指型計算
src/fretboard/fretboard.gd      # 指板繪製、懸停、位置命中與點選訊號
src/trainer/trainer.gd         # 三種模式、作答狀態、回饋與當次統計
src/trainer/trainer.tscn       # 主場景
src/audio/tone_player.gd       # 參考音合成、同步合奏、快取、音量與播放生命週期
src/ui/instrument_theme.gd    # 共用面板、按鍵、顯示區與語義色彩
src/ui/interval_key.gd        # 可操作的音程／和弦鍵，含公式、標示與選中指示
src/ui/faceplate.gd           # 儀器外殼與安裝標記
src/voice/voice_quiz.gd       # 獨立讀譜題目、聆聽 UI、判題、回饋與切題
src/voice/note_answer.gd      # 音名／固定唱名／升降／等音與信心判斷
src/voice/speech_bridge.gd    # 可替換的非同步語音輸入，macOS App 的 JSON 介面
src/voice/native/             # 原生 Swift Speech + AVAudioEngine 與權限說明
tools/build_voice_macos.sh   # 本機建立與 ad-hoc 簽署語音元件
tests/test_runner.gd          # 音樂模型與真實 viewport 點擊測試
tests/test_voice.gd           # 雙命名判題、真實 UI、原生 IPC、取消／過期結果
assets/fonts/                 # Noto Sans TC、Roboto Mono 及 SIL OFL
```

中文字型使用隨專案附帶的 [Noto Sans TC](https://github.com/google/fonts/tree/main/ofl/notosanstc)，等寬標示使用 [Roboto Mono](https://github.com/google/fonts/tree/main/ofl/robotomono)，均為 SIL OFL，授權位於 `assets/fonts/OFL.txt` 與 `RobotoMono-OFL.txt`。無需依賴作業系統已安裝的字型。所有資源使用 `res://` 路徑，不依賴其他遊戲專案。`artifacts/` 為驗證圖片、音訊與日誌，以 `.gdignore` 排除 Godot 匯入。

## 驗證

```sh
godot --headless --path games/guitar-intervals --editor --import --quit
godot --headless --path games/guitar-intervals --script res://tests/test_runner.gd
```

實際圖形渲染與截圖驗證：

```sh
godot --path games/guitar-intervals --script res://tests/test_runner.gd -- --capture-dir=/tmp/fret-relations
```

測試包含全部 96 個根音位置、12 種音級關係、兩種範圍、四種三和弦，以及滑鼠點選查閱、錯答重試、提示、揭答、取消選音、先選五度、統計與題目切換。聲音測試以頻譜偵測確認單音與和弦各聲部的實際 PCM 頻率，並透過 AudioEffectCapture 檢查引擎音訊匯流排確實輸出非零樣本；另驗證靜音、音量、跨八度、重播計分與白圈生命週期。圖形模式額外輸出畫面及單音／雙音／三和弦 WAV 預覽。

口說模式另執行 `godot --path games/guitar-intervals --script res://tests/test_voice.gd -- --capture-dir=/tmp/fret-voice`。測試會啟動已編譯的原生 App 走測試結果協定，並驗證雙命名、低信心／衝突候選、錯答、等音、提示／揭答、逾期結果隔離與自動切題；不會請求權限或錄音。這些測試不代表真人麥克風辨識準確度，仍需使用者授權後以實際發音驗證。

## 原型邊界與後續方向

目前是桌面視聽學習原型，尚未提供真實吉他取樣、麥克風辨識、替代調弦、左手指板、七弦琴、進度存檔、混合音程出題、手機版或匯出安裝檔。

後續可優先驗證：使用者能否把三度與六度的位置記憶遷移到不同根音；再依結果加入弱項重複練習、限定弦組、三和弦轉位與聽辨題。指定音高方向／八度的進階題型應使用實際 MIDI 差距判題，與目前的音級練習明確區分。
